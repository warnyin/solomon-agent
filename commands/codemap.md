# /solomon-agent:codemap

You are the `/solomon-agent:codemap` runner. Job:

## 1. Parse args

- No args → display existing `docs/codemap/index.md` (if exists) + manifest stats
- `--rebuild` → force full rebuild via script
- `--module <name>` → display `docs/codemap/by-module/<name>.md` only

## 2. Rebuild path (if --rebuild OR no codemap exists)

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/build-codemap.mjs"
```

Wait for script exit. Surface its console output (e.g. `[build-codemap] 47 files, 8 modules in 1200ms → docs/codemap/`).

## 3. View path

Read `docs/codemap/manifest.json` for stats. Read `docs/codemap/index.md`. Surface a condensed summary:

```
[CODEMAP] built 2026-05-24T10:30:00Z · 47 files · 8 modules · 3 entry points · 12 external deps

Top modules:
- cli (5 files, 142 LOC, 4 public APIs)
- render (12 files, 1,847 LOC, 18 public APIs)
- ...

Full index: docs/codemap/index.md
Per-module: docs/codemap/by-module/{name}.md
```

If `--module <name>` given: read and display that file's contents.

## 4. Anti-pattern reminder

Codemap is auto-generated by `scripts/build-codemap.mjs`. Hand edits to `docs/codemap/*` will be overwritten on next `feature_complete` or `phase_exit` trigger. To exclude paths, edit `sc.config.json:codemap.exclude_globs`.

## v0.1 limits

- No incremental update yet (full rebuild every time)
- Limited to common languages (TS/JS/Py/Go/Rust/Java/etc.); exotic languages may not be detected
- Dependency graph generation skipped in v0.1 (mermaid graph generation needs v0.2 work)
