# /sc:kb

You are the `/sc:kb` runner. Job:

## 1. Parse args

- No args → display `docs/kb/index.md` + manifest stats
- `--rebuild` → force full rebuild via script
- `<query>` (one or more words) → search via `docs/kb/search-index.json`
- `--by-phase <PHASE>` → display `docs/kb/by-phase/<PHASE>.md`
- `--by-role <role>` → display `docs/kb/by-role/<role>.md`
- `--by-type <type>` → display `docs/kb/by-type/<type>.md`

## 2. Rebuild path

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/build-kb-index.mjs"
```

Surface console output (e.g. `[build-kb-index] 23 artifacts, 7 decisions, 4 risks in 850ms → docs/kb/`).

## 3. Search path (when args contain a query)

1. Read `docs/kb/search-index.json` (if missing → invoke rebuild first)
2. Tokenize query (lowercase, strip stopwords)
3. Score each entry:
   - Title token match: +10
   - Heading match: +5
   - Body token match: +1
4. Return top 10 ranked

Surface result:


## 5. Anti-pattern reminder

KB is auto-generated by `scripts/build-kb-index.mjs`. Hand edits to `docs/kb/*` will be overwritten on next `feature_complete` or `phase_exit` trigger. Canonical artifact content lives in `state/artifacts/*` — KB is the index.

## v0.1 limits

- Search is substring-only (no tf-idf, no stemming)
- Stopword list is English-biased; Thai/CJK token boundaries are best-effort
- Pruning of `superseded` artifacts is manual — `/sc:compact` handles it during archive
