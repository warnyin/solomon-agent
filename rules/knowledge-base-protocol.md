# Knowledge Base Protocol

> Round 14: every artifact produced (`state/artifacts/*.md`) gets indexed into a navigable, searchable knowledge base under `docs/kb/`. Refreshed on every feature complete + phase exit. Companion to codemap (which indexes code, not artifacts).

## Why

After 30+ artifacts in a project, finding "the design decision about auth" via grep is painful. KB gives roles, owner, and the operator a curated index — by phase, by role, by type, by decision — so prior knowledge is reusable, not lost.

## Update Triggers

| Trigger | Source | What rebuilds |
|---|---|---|
| `feature_complete` | `rules/handoff-checkpoint-protocol.md` | full rebuild |
| `phase_exit` | owner-ceo | full rebuild |
| `manual` | `/sc:kb` user command | full rebuild |
| `artifact_signed_off` | role completion (status=approved) | incremental (new artifact only) |

## search-index.json Structure (lightweight, no extra deps)

```json
{
  "schema_version": 1,
  "built_at": "2026-05-24T10:30:00Z",
  "artifacts_indexed": 23,
  "entries": [
    {
      "id": "01H_DESIGN_F005",
      "path": "state/artifacts/01H_DESIGN_F005-DESIGN-sa-architecture.md",
      "title": "F-005 Image Embedding Architecture",
      "role": "role-sa",
      "phase": "DESIGN",
      "type": "design",
      "tokens": ["image", "embed", "base64", "fetch", "stream", "..."],
      "headings": ["## Components", "## Data Flow", "## Key Decisions"]
    }
  ]
}
```

Search is greedy substring over `tokens` + `title` + `headings`; no fancy tf-idf in v0.1. Returns ranked artifact list with snippet from first matching line.

## How `/sc:kb <query>` works

1. Read `docs/kb/search-index.json`
2. Tokenize query (lowercase, strip stopwords)
3. Score each entry: title match=10, heading match=5, body token match=1
4. Top 10 by score → display with snippet + path

## Pruning Policy

- `superseded` artifacts kept in KB for 1 phase boundary then moved to `docs/kb/archive/<project_id>/`
- `rejected` artifacts kept for 2 review cycles then archived
- KB size bounds: ≤ 5MB total; if exceeded, oldest archived artifacts go first
- Archive retains symlinks/references from decisions/risks so traceability survives

## Anti-Patterns

- Hand-editing `docs/kb/*` (overwritten next build)
- Indexing draft artifacts (only `approved` + `ready_for_review` in KB)
- Treating KB as substitute for `state/artifacts/*` (KB is index; canonical content is artifact)
- Excluding waiver decisions from `decisions.md` (transparency requirement)

## Events Emitted

- `kb_build_start` — trigger, scope
- `kb_build_complete` — artifacts_indexed, decisions_count, duration_ms
- `kb_archive_rotated` — old_count, archive_dir
- `kb_search_query` — query, result_count (for usage analytics)

## Integration

- `commands/kb.md` — `/sc:kb` view + search
- `scripts/build-kb-index.mjs` — implementation
- `rules/handoff-checkpoint-protocol.md` — `feature_complete` triggers rebuild
- `rules/codemap-protocol.md` — sibling system (codemap = code, KB = artifacts)
- `rules/memory-schema.md` — KB decisions duplicate to memory MCP `Decision` entities
- `rules/handoff-protocol.md` — final HANDOFF report links KB index for ongoing reference
