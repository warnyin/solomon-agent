# Codemap Protocol

> Round 14: every feature completion (and every phase exit) refreshes a code-level table-of-contents under `docs/codemap/` so any role or future operator can navigate the project without re-discovery cost.

## Why

A 50-file project's structure is forgotten by Turn 30. Without a maintained codemap, role-developer re-greps the same files every dispatch, role-qa misses untested modules, role-security skips entry points. Codemap = the project's living index.

## Update Triggers

| Trigger | Source | What rebuilds |
|---|---|---|
| `feature_complete` | `rules/handoff-checkpoint-protocol.md` | full rebuild |
| `phase_exit` (BUILD, VERIFY) | owner-ceo | full rebuild |
| `manual` | `/sc:codemap` user command | full rebuild |
| `code_artifact_written` | role-developer artifact write | incremental (touched files only) |

## File Layout

```
docs/codemap/
├── index.md                    # Top-level TOC (auto-generated)
├── by-module/
│   ├── <module-name>.md        # One per module: purpose, public API, deps, tests, owner-role
│   └── ...
├── by-feature/
│   ├── <feature-id>.md         # One per delivered feature: files touched, tests, artifacts produced
│   └── ...
├── dependency-graph.md         # Module → module dependency table + mermaid graph
├── entry-points.md             # CLI / HTTP / event handlers / cron jobs
├── data-stores.md              # DBs, queues, caches, files-as-store
├── external-integrations.md    # 3rd-party APIs, MCPs, webhooks
└── manifest.json               # codemap metadata: built_at, files_indexed, version
```

## Detection Heuristics (in `scripts/build-codemap.mjs`)

- **Modules**: top-level directories under `src/` (or per-language conventions: `pkg/` for Go, `app/` for Django, `crates/` for Rust workspaces)
- **Public API**: exported symbols per language; Node uses `export`, Python uses `__all__` + non-underscore, Go uses Capitalized, Rust uses `pub`
- **Entry points**: detect by file pattern: `cli.ts|bin/*|main.go|__main__.py|server.ts|index.js`
- **Tests**: directories matching `tests/`, `__tests__/`, `*.spec.*`, `*.test.*`
- **External deps**: parse package.json/Cargo.toml/go.mod/pyproject.toml/requirements.txt
- **Data stores**: detect `Database|Pool|Redis|Queue|Cache|Bucket` keywords + connection strings in env-ref form
- **External integrations**: detect `fetch|axios|httpx|reqwest` + URL string patterns + MCP usage

## Performance Bounds

- Full rebuild: ≤ 5 seconds for projects up to 1000 files; ≤ 30 seconds for 10k files
- Incremental: ≤ 500ms for single-file change
- If exceed bound → emit `codemap_slow` warning event; user MAY tune via `sc.config.json:codemap.exclude_globs`

## Excludes (default)

- `node_modules/`, `dist/`, `build/`, `target/`, `.next/`, `__pycache__/`, `.venv/`, `*.min.js`, generated files marked with `// @generated`
- Override via `sc.config.json: { "codemap": { "exclude_globs": [...] } }`

## Code-Map vs Brownfield code-map (clarity)

- **This protocol** (`codemap-protocol.md`) = ongoing project TOC, refreshed on feature complete. Output: `docs/codemap/*`. Read by every role for navigation.
- **Brownfield code-map artifact** (per `rules/existing-codebase-protocol.md`) = one-shot at DISCOVERY when starting on existing repo. Output: `state/artifacts/{ulid}-discovery-tl-code-map.md`. Used by role-tech-lead for delta analysis.

The two are complementary; brownfield artifact captures the initial map, codemap protocol maintains living map thereafter.

## Anti-Patterns

- Editing `docs/codemap/*` by hand (will be overwritten next rebuild)
- Skipping rebuild "because only docs changed" — feature_complete trigger fires regardless
- Indexing `state/artifacts/*` as code (those are artifacts; index in KB instead — `rules/knowledge-base-protocol.md`)
- Stale `manifest.json` not updated atomically with index.md

## Events Emitted

- `codemap_build_start` — trigger, scope (full|incremental)
- `codemap_build_complete` — files_indexed, duration_ms, modules_count
- `codemap_build_failed` — error class, partial output preserved

## Integration

- `commands/codemap.md` — `/sc:codemap` manual trigger + view
- `scripts/build-codemap.mjs` — implementation
- `rules/handoff-checkpoint-protocol.md` — `feature_complete` triggers rebuild
- `rules/knowledge-base-protocol.md` — sibling system for artifacts (not code)
